2. DESCRIÇÃO DO PROJETO
==================================================

Who Is Here é um jogo de terror e sobrevivência desenvolvido na linguagem Python usando a biblioteca do pygame e execultado e formulado dentro do VScode, com estética em pixel art e ambientação em um antigo farol.

O jogador assume o papel de um faroleiro responsável por permanecer no local durante a noite. Ao longo da experiência, acontecimentos estranhos começam a ocorrer e a presença de fantasmas passa a fazer parte da rotina do personagem.

O jogo combina exploração limitada, gerenciamento de recursos, minigames tomada de decisões e elementos narrativos. O jogador precisa observar o ambiente, administrar seus recursos e tomar decisões para descobrir o que está acontecendo no farol e sobreviver aos acontecimentos sobrenaturais.


3. INSTRUÇÕES DE EXECUÇÃO
==================================================

Para executar o jogo, siga os passos abaixo:

1. Certifique-se de que o Python esteja instalado no computador.

2. Abra o projeto no Visual Studio Code (VS Code).

3. Certifique-se de que todos os arquivos e pastas do projeto estejam mantidos em suas localizações originais.

4. Abra o terminal integrado do VS Code.

5. Verifique se o Python está instalado utilizando:

   python --version

6. Instale a biblioteca Pygame, caso ainda não esteja instalada:

   pip install pygame

7. Após a instalação, execute o arquivo principal do jogo:

   python main.py

8. A janela do jogo será aberta e o jogo poderá ser iniciado.

O jogo foi desenvolvido e executado utilizando o Visual Studio Code (VS Code).

6. ESTRUTURA DO PROJETO
==================================================

O projeto é composto pelos seguintes arquivos e pastas:

- __pycache__ — pasta utilizada pelo Python para armazenar arquivos temporários relacionados à execução dos módulos.
- audio.py — responsável pelo gerenciamento dos áudios do jogo.
- ben.py — arquivo relacionado aos elementos e funcionalidades do personagem Ben.
- config.py — contém as configurações gerais do jogo.
- controle.py — responsável pelos controles e interações do jogador.
- dados_diario.py — armazena os dados e informações utilizados pelo diário.
- dados_fantasmas.py — armazena informações relacionadas aos fantasmas do jogo.
- dialogos.py — contém os diálogos utilizados durante a história.
- diario.py — responsável pelo funcionamento e exibição do diário.
- erro_diario.txt — arquivo utilizado para registrar informações relacionadas a erros do diário.
- eventos.py — responsável pelo gerenciamento dos eventos que acontecem durante o jogo.
- fantasmas.py — responsável pelo funcionamento e comportamento dos fantasmas.
- indicadores_status.py — responsável pela exibição e gerenciamento dos indicadores de status.
- inventario.py — responsável pelo sistema de inventário do jogador.
- jogo.py — contém a estrutura e funcionamento principal da lógica do jogo.
- main.py — arquivo responsável por iniciar a execução do jogo.
- mecanicas.py — contém as mecânicas e sistemas de interação do jogo.
- menu.py — responsável pelo menu e suas funcionalidades.
- minigame_farol.py — contém o funcionamento do minigame relacionado ao farol.
- notificacoes.py — responsável pelas notificações exibidas ao jogador.
- progresso.json — arquivo utilizado para armazenar dados de progresso.
- progresso_json.py — responsável pelo gerenciamento dos dados de progresso em formato JSON.
- radio.py — responsável pelo funcionamento do rádio e suas interações.
- recursos.py — responsável pelo carregamento e gerenciamento dos recursos utilizados no jogo.
- save.py — arquivo usado apenas como salvamento (não interfere no código)
- sons — pasta que contém os arquivos de som utilizados no jogo.
- status.py — responsável pelo sistema de status do jogador.
- telas.py — responsável pela criação e gerenciamento das telas e elementos visuais do jogo.

==================================================

O objetivo de Who Is Here é proporcionar uma experiência de terror baseada em investigação.

A experiência busca criar tensão por meio da atmosfera, da narrativa e da dúvida constante sobre o que realmente está acontecendo.
